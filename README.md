# Framia - A 2D graphics page created by 3.1 Pro
This is an animation completely generated using Gemini 3.1 Pro and Canvas. I got inspired from those Opus 5.5 animations on prompt-motion.com and this is my test with Gemini, using my own prompt and brand.

> [INFO]
> This is not a real product. I created this only for testing out the capabilities of the model.

## Workflow
- This time, I wrote the whole prompt by myself. I'm giving just the initial prompt here, as I have sent many messages to add new stuff and improve the frames.
- I didn't want to download or create additional assets, so I told Gemini to make everything on its own.
- The page uses GSAP for the animations. It's literally amazing!!

You can copy this prompt and modify it to make something different and better!
### Prompt
Here's the prompt:
```text
Create a mind-blowing launch animation for a an AI presentation software named "Framia".  I want the best and maximum quality output. Follow my instructions for the video.
<content>
- Create an intro screen displaying the logo of the app.
- Then the next slides should highlight the standard features seen in presentation software. It should have a clean UI. You have to generate the UI images by yourself.
- Include a slide that pans around the UI of the app.
- Then introduce viewers to "Framia AI", which is an on-device assistant for Framia. It helps users to create, edit and manage their slides.
- Then show a frame showing the app is cross-platform.
<content>
<style>
- Use "Google Sans Flex" font from Google Fonts
- Use a combination of rich colors like #ED254E, black and white for the slides.
- Use big bold font style for the frames.
- You can have some slides with text only, and some with 2-column layout including text and images side-by-side.
- Use short, catchy and professional text. Convey the idea/feature clearly without writing lots of text.
- You can add a semi-transparent grainy animated pattern behind the screen, this shouldn't appear over our content.
- Animation needs to be non-linear, bezier-curved timing that makes things look bouncy.
<style>
<must dos>
- This is a video, you don't need to generate things like video scrubber or playback controls.
- I need fullscreen content, that's smooth and attractive
- Focus on proper delivery of content, make sure things don't overlap and get hidden
<must dos>
```
### Model
- Model used: **Gemini 3.1 Pro**, with **Thinking - High**

**You need at least a Google AI Plus plan in order to access this model**
